# 무작위 H(색상) & S(채도) 조합 및 V(밝기) Fadeout 이펙트 업데이트 기록 (2026-07-31)

## 1. 개요 및 요구사항
- **요구사항**: 키를 타건할 때(예: `Q`키 또는 `W`키 입력 시) 각 키 타건 이벤트별로 **H(Hue - 색상)와 S(Saturation - 채도)가 함께 무작위(Random H, Random S)로 선택**되어 점등되고, 시간이 지남에 따라 **V(Value - 밝기)만 255에서 0으로 서서히 떨어지며 Fadeout** 되도록 구현.

---

## 2. 세부 변경 코드

### 2.1 `solid_reactive_simple_random_anim.h`
```c
static hsv_t SOLID_REACTIVE_SIMPLE_RANDOM_math(hsv_t hsv, uint16_t offset) {
    if (offset > 255) offset = 255;
    uint16_t hit_tick = g_last_hit_tracker.tick[0];
    hsv.h = (uint8_t)(hit_tick * 167 + 53);                // Random H (무작위 색상)
    hsv.s = (uint8_t)(128 + ((hit_tick * 97 + 31) % 128)); // Random S (무작위 채도)
    hsv.v = scale8(255 - offset, hsv.v);                   // V(밝기)만 Fadeout
    return hsv;
}
```

### 2.2 `solid_reactive_multiwide_random_anim.h`
```c
static hsv_t SOLID_REACTIVE_MULTIWIDE_RANDOM_math(hsv_t hsv, int16_t dx, int16_t dy, uint8_t dist, uint16_t tick) {
    uint16_t effect = tick + dist * 5;
    if (effect > 255) effect = 255;
    hsv.h = (uint8_t)(tick * 167 + 53);                // Random H (무작위 색상)
    hsv.s = (uint8_t)(128 + ((tick * 97 + 31) % 128)); // Random S (무작위 채도)
    hsv.v = qadd8(hsv.v, 255 - effect);                // V(밝기)만 Fadeout
    return hsv;
}
```

## 3. 시각적 연출 효과
- 키를 타건할 때마다 원색, 파스텔톤, 은은한 톤 등 다채롭고 오묘한 **무작위 (H, S) 색상 1개**가 켜진 후, 다른 색상으로 변조되지 않고 오직 밝기 `V`만 0으로 스르륵 줄어들며 깔끔하게 소멸됩니다.
