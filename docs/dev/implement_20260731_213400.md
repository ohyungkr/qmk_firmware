# 무작위 반응형 RGB 순수 rand() % 256 단일 색상 점등 후 Fade-out 구현 기록 (2026-07-31)

## 1. 이슈 및 명확한 요구사항
- **요구사항**: QMK 틱 오프셋이나 위치 추적에 의존하지 않고, 키가 눌리는 순간 **C 표준 `rand() % 256`로 단 1개의 무작위 색상(Hue)을 직접 선택**한 뒤, 그 키 위치에 해당 무작위 단색으로 점등되어 **색상 변동 없이 오직 밝기만 감소하며 Fade-out**되도록 완벽히 구현.

---

## 2. 해결 방안 및 메커니즘

### 2.1 LED별 무작위 상태 트래킹 배열 선언 (`keymap.c`)
```c
uint8_t random_key_hue[DRIVER_LED_TOTAL] = {0};
uint8_t random_key_val[DRIVER_LED_TOTAL] = {0};

bool process_record_user(uint16_t keycode, keyrecord_t *record) {
    if (record->event.pressed) {
        uint8_t led_idx = g_target_matrix_to_led_line[record->event.key.row][record->event.key.col];
        if (led_idx != NO_LED) {
            random_key_hue[led_idx] = rand() % 256; // 완전 무작위 HUE 선택
            random_key_val[led_idx] = 255;          // 점등
        }
    }
    ...
}
```

### 2.2 이펙트 프레임 렌더링 (`solid_reactive_simple_random_anim.h`)
```c
if (random_key_val[i] > 0) {
    hsv_t hsv;
    hsv.h = random_key_hue[i]; // 타건 시 rand()로 뽑힌 단 1개의 무작위 색상
    hsv.s = 255;
    hsv.v = scale8(random_key_val[i], rgb_matrix_config.hsv.v);

    // 밝기만 서서히 감소 (Fade-out)
    random_key_val[i] -= fade_step;
}
```

---

## 3. 결과
- 키를 타건할 때마다 100% 무작위 난수로 뽑힌 단 한 가지 색상(예: 빨간색)만으로 그 키에 불이 켜지며, 소멸될 때까지 **색상이 다른 색으로 변조되지 않고 온전한 단색으로 Fade-out** 됩니다.
