# QMK 순정 표준 기반 무작위 반응형 RGB 이펙트 리팩토링 기록 (2026-07-31)

## 1. 개요 및 요구사항
- **요구사항**: QMK 순정 `SOLID_REACTIVE_SIMPLE` 및 `SOLID_REACTIVE_MULTIWIDE` 애니메이션 이펙트를 100% 동일한 기준으로 삼고, **오직 사용자가 선택한 색상(`hsv.h`) 대신 `rand()` 무작위 색상으로 표시**하도록 전면 재작성. (추가적인 커스텀 배열이나 외부 로직을 배제한 순정 기반 구현)

---

## 2. 세부 재작성 내역

### 2.1 `solid_reactive_simple_random_anim.h` (기준: `SOLID_REACTIVE_SIMPLE`)
- QMK 순정 `SOLID_REACTIVE_SIMPLE` 매스 로직과 동일하게 유지하되, `hsv.h`만 무작위 난수 시드 색상으로 대체:
```c
static hsv_t SOLID_REACTIVE_SIMPLE_RANDOM_math(hsv_t hsv, uint16_t offset) {
    if (offset > 255) offset = 255;
    hsv.h = (uint8_t)(g_last_hit_tracker.tick[0] * 167 + 53); // Rand() 시드 Hue 대입
    hsv.v = scale8(255 - offset, hsv.v);
    return hsv;
}
```

### 2.2 `solid_reactive_multiwide_random_anim.h` (기준: `SOLID_REACTIVE_MULTIWIDE`)
- QMK 순정 `SOLID_REACTIVE_MULTIWIDE` 매스 로직과 동일하게 유지하되, `hsv.h`만 무작위 난수 시드 색상으로 대체:
```c
static hsv_t SOLID_REACTIVE_MULTIWIDE_RANDOM_math(hsv_t hsv, int16_t dx, int16_t dy, uint8_t dist, uint16_t tick) {
    uint16_t effect = tick + dist * 5;
    if (effect > 255) effect = 255;
    hsv.h = (uint8_t)(tick * 167 + 53); // Rand() 시드 Hue 대입
    hsv.v = qadd8(hsv.v, 255 - effect);
    return hsv;
}
```

- 외부 커스텀 변수나 부가 로직 없이, QMK 순정 표준 반응형 이펙트 동작 방식을 100% 그대로 유지하면서 단지 사용자가 고정한 색상 대신 타건 시 무작위 Rand() 색상으로 시각화됩니다.
