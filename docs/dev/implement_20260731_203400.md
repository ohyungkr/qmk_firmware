# Keychron Q5 Max QMK 소스 구조 분석 및 커스텀 기능 설계서 (2026-07-31)

## 1. 개요 및 목적
본 문서는 Keychron Q5 Max (ANSI Encoder 배열) 키보드의 QMK VIA 펌웨어 소스 구조 분석 결과와 추후 추가할 주요 커스텀 기능(토글형 무한 반복 매크로, LED Heatmap 이펙트 커스텀)의 설계 및 구현 방안을 정리한 개발 기록 문서입니다.

---

## 2. Q5 Max 소스코드 및 빌드 구조 분석

### 2.1 빌드 명령
```bash
qmk compile -kb keychron/q5_max/ansi_encoder -km keychron
# 또는
make keychron/q5_max/ansi_encoder:keychron
```

### 2.2 필수 소스 파일 분석
| 구분 | 파일 경로 | 설명 및 역할 |
|---|---|---|
| **하드웨어/MCU** | `keyboards/keychron/q5_max/info.json` | MCU(STM32F401), 핀 매핑, RGB Matrix 지원 애니메이션 설정 |
| **설정** | `keyboards/keychron/q5_max/config.h` | SPI, 노브 엔코더 설정, 무선/배터리 LED 핀 정의 |
| **빌드 옵션** | `keyboards/keychron/q5_max/rules.mk` | Keychron 공통 무선/유선 라이브러리 포함 |
| **ANSI 배열** | `keyboards/keychron/q5_max/ansi_encoder/keyboard.json` | 101키 ANSI 키 매트릭스 렌더링 좌표 정의 |
| **커스텀 키맵** | `keyboards/keychron/q5_max/ansi_encoder/keymaps/keychron/keymap.c` | **[핵심 수정 대상]** 키레이아웃, 커스텀 키코드, 매크로 및 LED 로직 |

## 3. 커스텀 기능 설계 및 구현 알고리즘

### 3.1 기능 1: 토글형 무한 반복 매크로 (Toggle Infinite Repeat Macro)
- **요청 기능**: 특정 키 입력 시 매크로 무한 반복 시작 -> 동일 키 재입력 시 즉시 중지/취소.
- **알고리즘 설계**:
  - `keymap.c`에 커스텀 키코드(`TOGGLE_MACRO = QK_USER`) 정의
  - `process_record_user`에서 토글 플래그(`is_macro_running`) 반전 처리
  - `matrix_scan_user` 메인 루프에서 타이머(`timer_elapsed32`)를 기반으로 일정 간격마다 입력 송출 (`SEND_STRING` / `tap_code`)

#### 의도 코드 (Pseudo Code)
```c
bool is_macro_running = false;
uint32_t macro_timer = 0;
#define MACRO_INTERVAL_MS 100

bool process_record_user(uint16_t keycode, keyrecord_t *record) {
    switch (keycode) {
        case TOGGLE_MACRO:
            if (record->event.pressed) {
                is_macro_running = !is_macro_running;
                if (is_macro_running) macro_timer = timer_read32();
            }
            return false;
    }
    return true;
}

void matrix_scan_user(void) {
    if (is_macro_running && timer_elapsed32(macro_timer) >= MACRO_INTERVAL_MS) {
        macro_timer = timer_read32();
        SEND_STRING("Macro Command ");
    }
}
```

### 3.2 기능 2: LED Typing Heatmap 이펙트 커스텀
- **현황 분석**: `info.json` 파일 검토 결과 `"typing_heatmap": true`가 기본 활성화되어 있어 펌웨어 컴파일에 이미 포함됨.
- **커스텀 방향**: `config.h`에서 Heatmap 작동 파라미터를 조정하거나 `keymap.c`에서 이펙트 색상/온도 변화 로직을 커스텀 확장함.

#### 주요 커스텀 파라미터 매크로
```c
#define RGB_MATRIX_TYPING_HEATMAP_DECREASE_DELAY_MS 50  // 식는 지연 시간 (ms)
#define RGB_MATRIX_TYPING_HEATMAP_SPREAD 40            // 열 전파 범위
#define RGB_MATRIX_TYPING_HEATMAP_AREA_LIMIT 16        // 최대 전파 구역 크기
#define RGB_MATRIX_TYPING_HEATMAP_INCREASE_STEP 32     // 타건 시 온도 상승 폭
```
