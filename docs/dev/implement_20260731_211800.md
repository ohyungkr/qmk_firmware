# Keychron Q5 Max VIA 정의 JSON 파일 커스텀 업데이트 기록 (2026-07-31)

## 1. 개요
- **목적**: Keychron Q5 Max (ANSI Encoder) 키보드의 외부 및 프로젝트 내부 VIA 정의 JSON 파일(`q5_max_ansi_knob_v1.0_via.json`, `q5_max_ansi_encoder.json`)에 신규 무작위 반응형 RGB 이펙트 2종 및 무한 반복 매크로 커스텀 키코드 16종(`RPT0`~`RPT15`)을 등록하여 웹 기반 VIA / Keychron Launcher UI에서 사용자가 직접 선택/할당 가능하도록 확장.

---

## 2. 수정된 파일 목록
1. `G:\DownLoad\__Keyboard\Keychron_New\q5_max_ansi_knob_v1.0_via.json` (외부 VIA 정의 파일)
2. `keyboards/keychron/q5_max/via_json/q5_max_ansi_encoder.json` (프로젝트 내부 VIA 정의 파일)

---

## 3. 세부 수정 항목

### 3.1 RGB Matrix Effect 드롭다운 목록 추가
`menus` -> `Lighting` -> `Effect` 드롭다운 메뉴에 신규 애니메이션 이펙트 2종 추가:
- `["Reactive Simple Random", 19]`
- `["Reactive Multiwide Random", 21]`

### 3.2 Custom Keycodes 커스텀 키 탭 버튼 추가
`customKeycodes` 배열에 `Repeat Macro 0` ~ `Repeat Macro 15` (`RPT0` ~ `RPT15`) 버튼 등록:
```json
{"name": "Repeat Macro 0", "title": "Repeat Macro 0 (Toggle)", "shortName": "RPT0"},
...
{"name": "Repeat Macro 15", "title": "Repeat Macro 15 (Toggle)", "shortName": "RPT15"}
```
