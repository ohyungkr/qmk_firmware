# Keychron Q5 Max QMK VIA GitHub Fork 연동 기록 (2026-07-31)

## 1. 개요 및 요청 사항
- **요청 사항**: Keychron 공식 저장소(`Keychron/qmk_firmware`)를 개인 GitHub 계정(`ohyungkr`)으로 포크(Fork)하여 개인 저장소 기반으로 개발/관리하도록 구성.
- **작업 환경**: Windows 11, PowerShell, GitHub CLI (`gh`), Git.

---

## 2. 작업 수행 내용

### 2.1 GitHub Fork 생성 및 Remote 재구성
1. `gh repo fork Keychron/qmk_firmware --clone=false` 명령을 실행하여 `ohyungkr/qmk_firmware` 저장소 포크 생성.
2. 기존 `origin` (Keychron 공식)을 `upstream`으로 변경:
   ```bash
   git remote rename origin upstream
   ```
3. 개인 포크 저장소를 새로운 `origin`으로 등록:
   ```bash
   git remote add origin https://github.com/ohyungkr/qmk_firmware.git
   ```
4. 로컬 커밋 내역 및 `wireless_playground` 브랜치를 `origin`에 Push:
   ```bash
   git push -u origin wireless_playground
   ```

---

## 3. 설정된 Remote 정보
- **origin**: `https://github.com/ohyungkr/qmk_firmware.git` (개인 포크 저장소 - Push/Pull 작업)
- **upstream**: `https://github.com/Keychron/qmk_firmware.git` (Keychron 공식 원본 저장소 - 최신 소스 동기화용)
