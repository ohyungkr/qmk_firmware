# 타건 시 `rand() % 256` 고정 난수 색상 부여 및 Fadeout 구현 기록 (2026-07-31)

## 1. 개요 및 요구사항
- **요구사항**: 키를 타건하는 딱 그 시점에 `rand() % 256` 난수 생성기를 딱 1번만 작동시켜 고정된 단일 무작위 색상을 결정하고, 그 고정된 색상 그대로 켜졌다가 Fadeout 되도록 구현.

---

## 2. 세부 구현 로직

### 2.1 `keymap.c` - 타건 순간 `rand() % 256` 1회 선택 및 고정 저장
```c
uint8_t g_key_rand_hues[DRIVER_LED_TOTAL];
uint8_t g_hit_rand_hues[256];

bool rgb_matrix_record_key_press_user(uint8_t row, uint8_t col) {
    uint8_t led_index = g_target_matrix_to_led_line[row][col];
    if (led_index != NO_LED) {
        g_key_rand_hues[led_index] = (uint8_t)(rand() % 256); // 타건 순간 딱 1번 rand() % 256 선택
    }
    if (g_last_hit_tracker.count < 256) {
        g_hit_rand_hues[g_last_hit_tracker.count] = (uint8_t)(rand() % 256);
    }
    return true;
}
```

### 2.2 애니메이션 매스 함수 - 고정 `rand() % 256` 색상 적용
- `solid_reactive_simple_random_anim.h`:
  - `hsv.h = g_key_rand_hues[g_last_hit_tracker.index[0]];`
  - 순정 `SOLID_REACTIVE_SIMPLE`과 동일하게 작동하되 색상만 타건 시 1회 추출된 `rand() % 256` 고정 무작위 색상 적용.
- `solid_reactive_multiwide_random_anim.h`:
  - `hsv.h = g_hit_rand_hues[...]`
  - 순정 `SOLID_REACTIVE_MULTIWIDE`와 동일하게 작동하되 파동 색상만 타건 시 1회 추출된 `rand() % 256` 고정 무작위 색상 적용.
