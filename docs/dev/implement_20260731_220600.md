# QMK 컴파일 미선언 심볼 에러 수정 기록 (2026-07-31)

## 1. 컴파일 에러 발생원인
- `keymap_introspection.c` 등 QMK 코어 소스에서 `keymap.c`가 내포되어 컴파일될 때, RGB Matrix 헤더 파일 미포함으로 인해 `DRIVER_LED_TOTAL` 및 `g_target_matrix_to_led_line` 식별자가 미선언(undeclared) 에러를 유발.

---

## 2. 해결 방안

1. **`keymap.c`**:
   - `rgb_matrix.h` 헤더를 명시적으로 `#include`하고 `#ifdef RGB_MATRIX_ENABLE` 가드 처리.
   - 키 매트릭스 LED 인덱스 조회 방식을 QMK 표준 헬퍼인 `g_led_config.matrix_co[row][col]`로 전면 변경.
   - `DRIVER_LED_TOTAL`을 `RGB_MATRIX_LED_COUNT`로 매핑.

2. **`solid_reactive_simple_random_anim.h`**:
   - `extern uint8_t g_key_rand_hues[];` 크기 미정의 배열 선언으로 헤더 간 배열 크기 참조 종속성 제거.
