# SOLID_REACTIVE_SIMPLE_RANDOM 타건 시 `rand()` 고정 무작위 색상 구현 기록 (2026-07-31)

## 1. 구현 목표
- `SOLID_REACTIVE_SIMPLE_RANDOM` 이펙트 사용 시, 키를 타건하는 그 순간 C 표준 `rand()` 함수를 1회 호출하여 **선택된 단 하나의 무작위 색상(Single Fixed Random Hue)을 배열에 고정**하고, 소멸(Fadeout) 시까지 매 프레임 번쩍임 없이 해당 색상 그대로 깔끔하게 꺼지도록 구현.

---

## 2. 세부 구현 코드 구조

### 2.1 `keymap.c` - 키 타건 시 `rand()` 1회 호출 및 고정
```c
uint8_t g_key_rand_hues[DRIVER_LED_TOTAL];

bool rgb_matrix_record_key_press_user(uint8_t row, uint8_t col) {
    uint8_t led_index = g_target_matrix_to_led_line[row][col];
    if (led_index != NO_LED) {
        g_key_rand_hues[led_index] = (uint8_t)rand(); // 키 타건 시 rand() 1회 호출하여 색상 고정선점
    }
    return true;
}
```

### 2.2 `solid_reactive_simple_random_anim.h` - 고정 `rand()` 색상 사용 및 Fadeout
```c
extern uint8_t g_key_rand_hues[DRIVER_LED_TOTAL];

// 렌더링 루프에서는 매 프레임 rand()를 다시 부르지 않고, 타건 시 고정된 g_key_rand_hues[i] 값을 사용
hsv.h = g_key_rand_hues[i];
hsv.v = scale8(255 - offset, hsv.v); // Fadeout
```

## 3. 결과
- 키를 누르면 매 프레임 번쩍거림 없이, 타건 순간 `rand()`로 선점된 단 하나의 무작위 색상만 유지된 채 서서히 감쇄되며 꺼집니다.
