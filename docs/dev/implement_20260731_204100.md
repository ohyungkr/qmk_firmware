# Keychron Q5 Max 무작위 컬러 반응형 RGB 이펙트 구현 기록 (2026-07-31)

## 1. 개요 및 목적
- **목적**: 타건 시 단일 키 및 멀티 키 반응 영역에 100% 무작위(Random) 색상이 적용되는 2가지 커스텀 RGB Matrix 애니메이션 이펙트 추가 및 `info.json` 등록.
- **추가된 이펙트 명칭**:
  1. `SOLID_REACTIVE_SIMPLE_RANDOM`: 무작위 컬러 단일 키 반응형 이펙트
  2. `SOLID_REACTIVE_MULTIWIDE_RANDOM`: 무작위 컬러 멀티 와이드 파동 반응형 이펙트

---

## 2. 주요 파일 변경 및 신규 생성 내역

### 2.1 신규 애니메이션 헤더 파일 생성
1. **`quantum/rgb_matrix/animations/solid_reactive_simple_random_anim.h`**:
   - `g_rgb_timer` 및 타건 오프셋을 조합하여 0~255 범위의 난수 HUE를 생성하고 서서히 소멸(Fade-out)되는 반응형 매스 로직 작성.
2. **`quantum/rgb_matrix/animations/solid_reactive_multiwide_random_anim.h`**:
   - 파동 거리 `dist`, 델타 `dx`, `dy` 및 타임스탬프를 조합하여 멀티 와이드 스플래시 생성 시 무작위 HUE를 적용하는 반응형 스플래시 매스 로직 작성.

### 2.2 Core RGB Matrix 효과 목록에 포함 (`quantum/rgb_matrix/animations/rgb_matrix_effects.inc`)
- `#include "solid_reactive_simple_random_anim.h"`
- `#include "solid_reactive_multiwide_random_anim.h"` 포함을 완료하여 QMK 이펙트 enum 목록에 포함.

### 2.3 `keyboards/keychron/q5_max/info.json` 애니메이션 옵션 추가
- `rgb_matrix.animations` 섹션에 `"solid_reactive_simple_random": true`, `"solid_reactive_multiwide_random": true` 선언.

---

## 3. QMK MSYS 빌드 및 적용 방법

QMK MSYS 터미널에서 기존과 동일하게 컴파일을 수행합니다:

```bash
qmk compile -kb keychron/q5_max/ansi_encoder -km keychron
```

컴파일 시 신규 이펙트 2종이 자동 포함되며, `RGB_MOD` 키를 누르거나 Keychron Launcher / VIA에서 해당 이펙트를 선택하면 EEPROM 메모리에 자동 저장되어 지속 적용됩니다.
