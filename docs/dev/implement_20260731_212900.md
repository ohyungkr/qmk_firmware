# 무작위 반응형 RGB 단일 무작위 색상(Single Solid Hue) 유지 수정 기록 (2026-07-31)

## 1. 개요 및 요구사항
- **요구사항**: 타건 시 단일 무작위 색상(예: 빨간색)이 선택되었을 때, 켜지는 순간부터 소멸(Fade-out)되어 완전히 꺼질 때까지 **오직 그 한 가지 색상(Single Solid Hue)만 100% 유지**되며 소멸되도록 로직 수정.
- **수정 대상**: `solid_reactive_simple_random_anim.h`, `solid_reactive_multiwide_random_anim.h`

---

## 2. 세부 변경 내역

### 2.1 LED 위치/좌표 변수 제거 및 틱 시드 단일화
- 기존에 LED 위치 오프셋(`i`, `dx`, `dy`)이 Hue 계산식에 포함되어 한 번 타건 시 여러 색상이 무지개처럼 혼합되던 문제 제거.
- 오직 해당 타건 이벤트의 타임스탬프(`raw_hit_tick`, `g_last_hit_tracker.tick[j]`) 1개만을 시드로 사용하여 **타건 1회당 오직 단 하나의 고정 무작위 색상(Single Uniform Hue)**을 부여:
  ```c
  // solid_reactive_simple_random_anim.h
  hsv.h = (uint8_t)(raw_hit_tick * 167 + 53); // 단일 고정 무작위 Hue
  hsv.v = scale8(255 - offset, hsv.v);

  // solid_reactive_multiwide_random_anim.h
  uint8_t hit_hue = (uint8_t)(g_last_hit_tracker.tick[j] * 167 + 53); // 단일 고정 무작위 Hue
  hsv.h = hit_hue;
  hsv.v = qadd8(hsv.v, 255 - effect);
  ```

## 3. 효과 개선 결과
- 예: 특정 키 타건 시 초록색이 결정되면, 켜질 때부터 Fade-out되어 완전히 꺼질 때까지 다른 색상이 일절 섞이지 않고 **오직 초록색 1가지 색상만 유지되면서 깔끔하게 꺼집니다.**
