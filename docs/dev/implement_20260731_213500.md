# 타건 시 단일 `rand()` 선택 색상 유지 반응형 RGB 구현 기록 (2026-07-31)

## 1. 개요 및 요구사항
- **요구사항**: 복잡한 히트 트래커 시드 계산을 지양하고, **키를 타건하는 그 순간 `rand()`를 통해 선택된 단 하나의 무작위 색상(Single Random Hue)이 할당되어, 소멸(Fadeout) 시까지 100% 동일한 그 한 가지 색상만 유지**되며 소멸되도록 재작성.

---

## 2. 세부 구현 로직

### 2.1 `keymap.c` - 키 타건 시 `rand()` 무작위 색상 할당
- `rgb_matrix_record_key_press_user`에서 타건 발생 순간 `g_key_rand_hues[led_index] = (uint8_t)rand()`를 실행하여 단 1개의 색상 선택:
```c
uint8_t g_key_rand_hues[DRIVER_LED_TOTAL];

bool rgb_matrix_record_key_press_user(uint8_t row, uint8_t col) {
    uint8_t led_index = g_target_matrix_to_led_line[row][col];
    if (led_index != NO_LED) {
        g_key_rand_hues[led_index] = (uint8_t)rand();
    }
    return true;
}
```

### 2.2 애니메이션 이펙트 루프 - 해당 단일 색상 유지 및 Fadeout
- `solid_reactive_simple_random_anim.h`:
  - `hsv.h = g_key_rand_hues[i]`를 적용하여, 타건 시 `rand()`로 선택된 온전한 단 하나의 색상으로 켜진 후 밝기만 감소하며 Fadeout.
- `solid_reactive_multiwide_random_anim.h`:
  - `hsv.h = g_hit_rand_hues[j]`를 적용하여, 해당 스플래시 타건 이벤트의 `rand()` 단일 색상으로 파동 전체가 점등 후 Fadeout.
