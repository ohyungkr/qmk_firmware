# QMK REPEAT(M0) 무한 반복 매크로 키코드 구현 기록 (2026-07-31)

## 1. 개요 및 기능
- **목적**: Keychron Q5 Max 키맵에서 `REPEAT(M0)` ~ `REPEAT(M15)` 파라미터 매크로 형태로 키코드를 지정하여, 한 번 누르면 해당 VIA 매크로를 무한 반복하고 다시 누르면 즉시 취소/중지되는 커스텀 기능 구현.
- **적용 소스 파일**: `keyboards/keychron/q5_max/ansi_encoder/keymaps/keychron/keymap.c`

---

## 2. 세부 구현 알고리즘

### 2.1 매크로 인덱스 및 키코드 선언
```c
#define M0  0
#define M1  1
...
#define M15 15

enum user_custom_keycodes {
    RPT_M0 = QK_USER,
    RPT_M1,
    ...
    RPT_M15,
};

#define REPEAT(n) (RPT_M0 + (n))
```

### 2.2 키맵 할당 예시
```c
[MAC_BASE] = LAYOUT_ansi_101(
    KC_ESC, KC_BRID, KC_BRIU, KC_MCTRL, REPEAT(M0), REPEAT(M1), ...
)
```

### 2.3 제어 및 무한 반복 송출 로직
- `process_record_user`:
  - `RPT_M0` ~ `RPT_M15` 입력 시 동일 매크로 타건이면 `active_repeat_macro = -1`로 무한 반복 중지.
  - 신규 매크로 타건 시 `active_repeat_macro = target_macro`로 활성화.
- `matrix_scan_user`:
  - `active_repeat_macro >= 0` 상태일 때 100ms 간격으로 `dynamic_keymap_macro_send(active_repeat_macro)`를 호출하여 매크로 자동 무한 송출.
