# Keychron Q5 Max QMK VIA 펌웨어 최초 구현 및 세팅 기록 (2026-07-31)

## 1. 개요 및 타겟 이슈
- **이슈 내용**: Keychron Q5 Max (ANSI 배열) 커스텀 키보드의 QMK VIA 펌웨어를 컴파일하고 관리할 수 있도록 Git 저장소 세팅 및 문서화 구축.
- **작업 환경**: Windows 11, PowerShell, QMK MSYS, Git.

---

## 2. 작업 수행 내용

### 2.1 QMK 소스코드 동기화
- Keychron 무선 커스텀 QMK 공식 브랜치인 `https://github.com/Keychron/qmk_firmware.git` (`wireless_playground` 브랜치)를 저장소 최상위에 동기화.
- ANSI 배열 및 노브 엔코더 타겟인 `keyboards/keychron/q5_max/ansi_encoder` 경로 및 `via` 키맵 확인.

### 2.2 Git Ignore 설정 (`.gitignore`)
- 사용자 전역 보안 규칙에 따라 `./docs` 및 `./.agent` 디렉토리를 보안 기본 제외 대상으로 추가.
- QMK 컴파일 시 생성되는 바이너리(`*.bin`, `*.hex`, `*.uf2`) 및 중간 생성물(`.build/`) 제외 등록.

### 2.3 문서 체계 구축
- `README.md`: ANSI 키맵 타겟 및 QMK MSYS 빌드 요약
- `docs/manual.md`: QMK MSYS 빌드 가이드, 키맵 수정 위치, 펌웨어 DFU 플래싱 절차 상세 설명
- `docs/dev/implement_20260731_194748.md`: 현 구현 이력 작성

## 3. 핵심 타겟 로직 및 빌드 알고리즘

### Keychron Q5 Max ANSI 타겟 구조
- **MCU**: STM32F405 / ARM Cortex-M4
- **Keyboard Target**: `keychron/q5_max/ansi_encoder`
- **Keymap Target**: `via`
- **Build Command**:
  ```bash
  qmk compile -kb keychron/q5_max/ansi_encoder -km via
  ```
