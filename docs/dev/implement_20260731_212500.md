# 무작위 컬러 반응형 RGB 이펙트 Fade-out 색상 고정 개선 기록 (2026-07-31)

## 1. 이슈 및 피드백 내용
- **피드백**: 기존 무작위 컬러 반응형 이펙트(`SOLID_REACTIVE_SIMPLE_RANDOM`, `SOLID_REACTIVE_MULTIWIDE_RANDOM`) 사용 시, 시간이 흘러 소멸(Fade-out)되는 동안 Hue(색상)가 계속해서 알록달록 변하던 현상 개선 요청.
- **요구사항**: 키를 타건한 그 순간 생성된 무작위 색상(Color) 그대로 **Hue는 변하지 않고 고정**된 채, 밝기(`hsv.v`)만 감소하며 소멸되도록 수정.

---

## 2. 해결 방안 및 로직 수정

### 2.1 `solid_reactive_simple_random_anim.h`
- 타건 순간의 시드 틱(`raw_hit_tick`)과 LED 인덱스를 조합하여 **고정 무작위 HUE**를 산출:
  ```c
  hsv.h = (uint8_t)(raw_hit_tick * 167 + i * 97 + 53);
  hsv.v = scale8(255 - offset, hsv.v); // HUE 변화 없이 밝기만 감소
  ```

### 2.2 `solid_reactive_multiwide_random_anim.h`
- 각 타건 히트 지점 `j`의 고정 좌표(`x[j]`, `y[j]`)와 타임스탬프(`tick[j]`)를 이용하여 **파동 소멸 동안 고정된 무작위 HUE** 산출:
  ```c
  uint8_t hit_hue = (uint8_t)(g_last_hit_tracker.x[j] * 13 + g_last_hit_tracker.y[j] * 29 + g_last_hit_tracker.tick[j] * 101 + 37);
  hsv.h = hit_hue;
  hsv.v = qadd8(hsv.v, 255 - effect);
  ```

---

## 3. 효과 개선 결과
- 키를 누를 때마다 각기 다른 독특한 무작위 색상으로 불이 켜지며, 소멸될 때까지 **색상의 바램/변조 없이 깔끔하게 Fade-out** 됩니다.
